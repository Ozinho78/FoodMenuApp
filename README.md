## About the Project

**FoodMenuApp** is a personal learning project built with **Django**. The main goal of this project is to strengthen and maintain my backend development skills by working with the Django framework in a practical environment.

Beyond creating a functional web application, this project serves as a continuous learning platform to improve my Python and Django knowledge while following modern software development practices.

## Motivation

I currently work as a **Network Specialist**, focusing on network infrastructure, firewalls, and IT operations. In addition to my professional experience, I completed extensive training in **Frontend Development**, **Backend Development**, and **DevSecOps**.

Since software development is not part of my daily responsibilities, I regularly build personal projects like FoodMenuApp to keep my development skills up to date and continue learning through hands-on experience.
